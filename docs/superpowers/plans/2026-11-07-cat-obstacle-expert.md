# CAT 避障专家的首轮自动课程

1. 使用已验证的 balance50 Actor 开始。冻结原控制器增益、观测和风险引导，记录原模型、原协议、Git 提交和哈希。首关与每次晋级重新初始化 Critic 和优化器，关内按检查点恢复。
2. 依次验证 4 cm 地栏、8 cm 地栏、单低顶、低顶与地栏组合。仿真中使用完整 Unitree 六轴速度扰动与 CAT 随机 PD，训练与晋级评估使用同一扰动配置和独立种子。保留每关 600 次 PPO 更新、每 50 次保存、2 个种子各 128 局、226 局通过才晋级。初次训练并行环境数记录在协议中。
3. 固定走廊评估要求穿过障碍，在 2.5 秒内从离障面继续向前 0.35 m，恢复时连续 0.2 秒保持向前运动和躯干稳定。记录物理子步接触、跌倒、未穿过、过障后未恢复。评估结束条件是技能完成，末端站立另行评估。
4. 保存各关结果表和逐局数据。未达晋级线时停止后续关卡。完成静态课程后再接入滚动球、低空动态物体与机器人交会，届时为场景定义专用危险区和交接条件。
